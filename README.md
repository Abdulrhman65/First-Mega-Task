# Task Tracker - تطبيق إدارة المهام

مشروع بسيط تم تنفيذه بلغة C# لمتابعة وإدارة المهام اليومية من خلال شاشة الـ Console.

## المميزات الأساسية:
- إضافة مهمة جديدة (العنوان، الوصف، تاريخ الاستحقاق، والأولوية).
- تحديث حالة المهمة (معلقة - قيد التنفيذ - مكتملة).
- عرض المهام وتصنيفها تلقائياً إلى: (نشطة، متأخرة، ومكتملة).
- حذف المهام مع رسالة تأكيد قبل الحذف.
- إمكانية البحث عن المهمة بالـ ID أو بالعنوان لتعديلها أو حذفها.

---

## ملاحظة بخصوص الكود وهيكلة الـ OOP:
نظراً لضيق الوقت، كان تركيزي الأساسي منصبّ على استيفاء كل شروط ومتطلبات التاسك، والتأكد من معالجة المدخلات بشكل سليم عشان البرنامج ميحصلوش Crash.

عشان كدا، بعض مفاهيم الـ OOP وتصميم الكود لم تُطبّق بأفضل شكل ممكن:
- **فصل المسؤوليات (Separation of Concerns):** كلاس الـ `TaskManager` مدمج فيه بعض أجزاء واجهة المستخدم والتعامل المباشر مع الـ Console وكان الأفضل فصلها تماماً.
- **تغليف البيانات (Encapsulation):** يحتاج تنظيم أفضل في الوصول للبيانات.

إن شاء الله سيتم مراعاة النقط دي وتطبيقها بشكل أفضل في التاسكات والمشاريع القادمة.

---

## طريقة التشغيل:
1. افتح المشروع في Visual Studio أو عبر الـ Terminal.
2. شغّل الأمر:
```bash
dotnet run
```
